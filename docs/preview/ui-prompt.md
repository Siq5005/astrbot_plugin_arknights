# 生成 UI 设计稿

## 调用方式（关键点）

`gpt-image-2` 系列的 **`/v1/images/generations` 在部分中转网关上会 60 秒超时**，
但 **chat 通道可用**——前提是显式声明 `modalities`：

```bash
curl -sS https://<中转域名>/v1/chat/completions \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -d '{
        "model": "gpt-image-2.5-flare",
        "modalities": ["image", "text"],
        "messages": [{"role": "user", "content": "<下面的提示词>"}]
      }'
```

图片以 markdown 链接形式返回在 `choices[0].message.content` 里：

```
![image](https://..../xxx.png)
```

不加 `modalities` 时，账号池会回一句
`image generation isn't available in this temporary chat`（纯文本拒绝，不是报错）。

另外两点经验：

- 生成似乎有内容策略检查：提示词里出现「真实存在的角色名 + 立绘」容易被拒，
  用「银发女性角色半身立绘」这类描述即可。
- 返回的图片域名可能对部分服务器 IP 有 Cloudflare 拦截（`403 error code: 1010`），
  换一台机器下载即可。

## 提示词

```
设计一张「明日方舟」风格的深色数据面板 UI 设计稿（扁平界面设计图，不是照片、不是 3D 渲染、不是插画）。

【视觉规范·严格遵守】
- 背景近黑 #0A0B0D，面板 #121317，发丝级 1px 边框 #2B2F37
- 只有一种强调色：琥珀 #FFB400。正文白 #F2F4F7，标签灰 #8D939E
- 所有角一律直角，禁止圆角、禁止投影、禁止发光、禁止玻璃拟态
- 装饰只用极细线条与 4-6px 琥珀色实心块；卡片左上与右下各有一组琥珀色 L 形角标
- 标题下方一条 45° 斜向琥珀色危险条纹分隔带
- 分区标题小而宽字距、琥珀色，前缀两个斜杠 "//"
- 数字大而粗、等宽对齐；标签小、灰色、宽字距

【版式·从上到下】
1. 顶栏：左侧一块粗的琥珀色竖条，然后是大号粗体中文标题「罗德岛终端」；右侧小号灰色大写英文副标题 "RHODES ISLAND"
2. 斜向危险条纹分隔带
3. 左右两栏：左栏是一个竖长的深色画框，里面放一位银发女性角色半身立绘（动漫风格占位图），画框底部有一条细琥珀色下划线和一个小的琥珀色职业徽章；右栏上方是一条由三格组成的数据条（每格：上方小灰标签，下方大号粗体数值），格与格之间用 1px 竖线分隔；下方再一条两格的数据条
4. 分区「// 理智」：两行「标签+数值」，中间一条 6px 细琥珀色进度条
5. 分区「// 进度」：三行「标签+数值」，每行下面一条细进度条，最后一条部分填充
6. 分区「// 助战干员」：一行三张小方形干员头像缩略图，每张下面一行极小说明文字
7. 页脚：左右两段极小灰色文字，与主体之间用一条 1px 细线分隔；页脚区域再加一个极小的条形码和编号

整体要像一张干净、克制、锐利的真实 HTML/CSS 后台界面稿。所有中文文字必须清晰可读、不得乱码。
```

## 插件图标提示词

```
一个正方形的手机 App 图标，明日方舟风格的工业数据终端主题。
背景为近黑色 #0A0B0D，只使用一种强调色：琥珀色 #FFB400。
图标中心是一个极简的徽记：一个方形的终端屏幕轮廓，屏幕内有一条水平的琥珀色扫描线，
屏幕右侧延伸出三根递增的信号竖条。徽记外围左上与右下各有一组琥珀色 L 形角标，
底部一段 45 度斜向危险条纹。
扁平矢量风格，直角，禁止圆角、禁止投影、禁止渐变、禁止玻璃质感、禁止 3D。
构图居中、留白充足，要能在 64x64 的小尺寸下清晰辨认。
画面中不要出现任何人物、文字或字母。
```

> 生图会在图形周围留下大片暗色留白，且背景带一层很暗的圆盘，按亮度裁切无效。
> 只对**明亮琥珀色像素**求包围盒（并用 2% 分位剔除边缘杂点）后再居中重排，
> 才能让徽记占满画面。
